# 9. Avaliação por pares

## 9.1 Organização do trabalho

O projeto será desenvolvido individualmente por **Denver Ritter**. Dessa forma, não serão atribuídas atividades ou avaliações fictícias a integrantes inexistentes.

## 9.2 Instrumento sugerido para avaliação por pares

Caso a disciplina disponibilize colegas avaliadores ou um formulário próprio, a avaliação deverá seguir as orientações do professor. Como apoio, podem ser considerados os seguintes aspectos:

| Critério | Aspecto observado |
|---|---|
| Clareza | O problema e a solução estão compreensíveis? |
| Requisitos | Os requisitos representam necessidades reais dos usuários? |
| Banco de dados | As tabelas, atributos e relacionamentos atendem às regras de negócio? |
| Tecnologias | As tecnologias estão listadas com links oficiais? |
| Design | As telas são coerentes com o público e as funcionalidades? |
| Viabilidade | O escopo é compatível com o tempo e os recursos disponíveis? |

## 9.3 Registro da avaliação

A nota de avaliação por pares, quando realizada, deverá ser registrada conforme o procedimento definido pela instituição ou pelo professor. Não serão inventados nomes, comentários ou notas de avaliadores.
